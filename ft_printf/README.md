# ft_printf

A formatted-output library using variadic arguments and custom format parsing.

Supports `%c`, `%s`, `%p`, `%d`, `%i`, `%u`, `%x`, `%X` and `%%`. The shared version also contains helpers for formatted output to file descriptors, and relies on [libft](../libft/) for string utilities.

```bash
make -C libft
make -C ft_printf
```

**Focus:** variadic functions, numeric conversions and modular C libraries.
